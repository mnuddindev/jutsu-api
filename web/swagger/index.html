Jutsu API Documentation

A blazing-fast, production-ready RESTful API for anime streaming platforms. Built with Go and Fiber for maximum performance and scalability. This API provides comprehensive anime data including episodes, metadata, streaming sources, characters, voice actors, schedules, and more.

Base URL http://localhost:8080/api
Current Version v1.0.0
Format JSON
Error Handling

All error responses follow a consistent format: 

{
  "success": false,
  "message": "Error description"
}
