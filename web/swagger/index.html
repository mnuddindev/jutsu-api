High-performance REST API

Modern anime data service built in Go

Unified endpoints for spotlights, rich anime metadata, streaming sources, schedules, characters, studios, search, and observability — all backed by Go Fiber, Redis caching, and structured logging.

Explore API Reference View source

Base URL

http://localhost:8080/api

Formats

JSON · UTF-8

Rate limiting

Not enforced (self-manage)

Quick start

Call any endpoint via HTTPS — no auth required.

Install deps

make install

Run server

make run

Generate docs

make swagger 
curl "http://localhost:8080/api/"

Error model

Every failure response returns a consistent envelope.

{
  "success": false,
  "message": "Why the request failed"
}

Endpoint reference

Each section mirrors the layout in docs/API.md with request and response samples.

GET /api Home

Home info

Spotlights, trending, top ten, schedule snapshot, and quick category previews.

Example request

curl http://localhost:8080/api

Example response

{
  "success": true,
  "results": {
    "spotlights": [...],
    "trending": [...],
    "topTen": {
      "today": [...],
      "week": [...],
      "month": [...]
    },
    "today": { "schedule": [...] },
    "topAiring": {...},
    "mostPopular": {...},
    "genres": ["action", "adventure", ...]
  }
}

Top ten

Curated rankings for today, week, and month.

Example request

curl http://localhost:8080/api/top-ten

Example response

{
  "success": true,
  "results": {
    "today": [...],
    "week": [...],
    "month": [...]
  }
}
GET /api/info Anime

Anime info

Detailed synopsis, stats, seasons, related and recommended shows.

Example request

curl "http://localhost:8080/api/info?id=frieren-beyond-journeys-end-18542"

Example response

{
  "success": true,
  "results": {
    "data": {
      "id": "frieren-beyond-journeys-end-18542",
      "title": "Frieren: Beyond Journey's End",
      "poster": "https://...",
      "description": "...",
      "genres": [...]
    },
    "seasons": [...],
    "relatedAnime": [...],
    "recommended": [...]
  }
}
GET /api/{routeType} Categories

Categories & genres

Supports `genre/*`, `top-airing`, `most-popular`, `completed`, `recently-updated`, `movie`, `tv`, `ova`, `ona`, `special`, and `az-list/*` routes.

Example request

curl "http://localhost:8080/api/genre/action?page=1"

Example response

{
  "success": true,
  "results": {
    "totalPages": 10,
    "data": [
      {
        "id": "anime-id",
        "title": "Anime Title",
        "poster": "https://...",
        "tvInfo": {...}
      }
    ]
  }
}
GET /api/producer/:id Studios

Producer catalogue

Paginated listing of anime associated with a producer.

Example request

curl "http://localhost:8080/api/producer/studio-pierrot?page=1"

Example response

{ "success": true, "results": { "totalPages": 5, "data": [...] } }
GET /api/studio/:id Studios

Studio catalogue

Studio-specific anime listings with pagination identical to producer endpoint.

Example request

curl "http://localhost:8080/api/studio/studio-pierrot?page=1"

Example response

{ "success": true, "results": { "totalPages": 5, "data": [...] } }
GET /api/search Search

Search

Keyword search with optional filters for type, status, rating, language, season, and date ranges.

Example request

curl "http://localhost:8080/api/search?keyword=naruto&type=tv&page=1"

Example response

{
  "success": true,
  "results": {
    "data": [...],
    "page": 1,
    "totalPage": 5,
    "hasNext": true
  }
}
GET /api/filter Search

Filter

Advanced catalogue filtering with identical parameters to search for builder-style UIs.

Example request

curl "http://localhost:8080/api/filter?type=tv&status=ongoing&genres=1,2,3&page=1"

Example response

{ "success": true, "results": { "data": [...], "page": 1, "hasNext": true } }
GET /api/search/suggest Search

Search suggestions

Autocomplete suggestions for instant search boxes.

Example request

curl "http://localhost:8080/api/search/suggest?keyword=naru"

Example response

{ "success": true, "results": [{ "id": "naruto", "title": "Naruto", "poster": "https://..." }] }

GET /api/episodes/:id Episodes

Episode list

Returns ordered episodes with filler flags for a show.

Example request

curl "http://localhost:8080/api/episodes/frieren-beyond-journeys-end-18542"

Example response

{ "success": true, "results": { "episodes": [{ "number": 1, "title": "Episode 1", "isFiller": false }] } }
GET /api/servers Streaming

Servers

Lists available streaming servers for a given episode.

Example request

curl "http://localhost:8080/api/servers?ep=107257"

Example response

{ "success": true, "results": [{ "type": "sub", "serverName": "Vidcloud", "server_id": 123 }] }
GET /api/stream/:id Streaming

Stream

Primary streaming sources, captions, intros/outros, and server metadata.

Example request

curl "http://localhost:8080/api/stream/frieren-beyond-journeys-end-18542?ep=107257&server=hd-1&type=sub"

Example response

{
  "success": true,
  "results": {
    "streamingLink": [{ "type": "sub", "link": { "file": "https://..." }, "tracks": [...] }],
    "servers": [...]
  }
}
GET /api/stream/fallback/:id Streaming

Stream fallback

Graceful fallback streams when the primary CDN fails.

Example request

curl "http://localhost:8080/api/stream/fallback/frieren-beyond-journeys-end-18542?ep=107257&server=hd-1&type=sub"

Example response

{ "success": true, "results": { "streamingLink": [...], "servers": [...] } }

GET /api/schedule Schedule

Daily schedule

Timezone-aware airing schedule for the requested date.

Example request

curl "http://localhost:8080/api/schedule?date=2025-01-18&tzOffset=-330"

Example response

{ "success": true, "results": [{ "id": "anime-id", "time": "12:00", "episode": 12 }] }
GET /api/schedule/:id Schedule

Next episode schedule

Returns the next airing time for a specific series.

Example request

curl "http://localhost:8080/api/schedule/frieren-beyond-journeys-end-18542"

Example response

{ "success": true, "results": { "nextEpisodeSchedule": "2025-01-25T12:00:00Z" } }

Live

Schema primer

Key payloads surfaced most frequently across the API.

Spotlight

Used in home responses for hero tiles.

id
string · example: frieren-beyond-journeys-end-18542
data_id
string
title
string · localized title
poster
string<uri>
description
string
tvInfo
object with showType, duration, releaseDate, quality, episodeInfo

Example

{
  "id": "frieren-beyond-journeys-end-18542",
  "title": "Frieren: Beyond Journey's End",
  "poster": "https://...",
  "tvInfo": {
    "showType": "TV",
    "duration": "24m",
    "quality": "HD"
  }
}

AnimeCard

Compact tile used in search, categories, watchlist.

id
string
title
string
poster
string<uri>
duration
string
rating
string
episodes
object { sub, dub }
{ "id": "anime-id", "title": "Anime Title", "rating": "4.8", "episodes": { "sub": 12, "dub": 12 } }

AnimeDetail

Full payload returned by info/random endpoints.

results.data
Core anime metadata (title, poster, synopsis, stats)
seasons
array of related seasons
relatedAnime
array<AnimeCard>
recommended
array<AnimeCard>
{
  "success": true,
  "results": {
    "data": { "id": "frieren-...", "title": "Frieren" },
    "seasons": [...],
    "relatedAnime": [...]
  }
}

StreamInfo

Streaming payload with tracks and fallback info.

streamingLink
array of sources with file/type + tracks + intro/outro
servers
array of server metadata (type, serverName, ids)
{
  "streamingLink": [{ "type": "sub", "link": { "file": "https://..." }, "tracks": [...] }],
  "servers": [{ "serverName": "Vidcloud" }]
}

ScheduleItem

Used across schedule endpoints.

id
string
title
string
releaseDate
string (YYYY-MM-DD)
time
string (localized time)
episode_no
integer
{ "id": "anime-id", "title": "Anime Title", "releaseDate": "2025-01-18", "time": "12:00" }

SearchResult

Envelope for search/filter endpoints.

page
integer
totalPage
integer
hasNext
boolean
data
array<AnimeCard>
                                    { 
                                        "page": 1, 
                                        "totalPage": 5, 
                                        "hasNext": true, 
                                        "data": [
                                            { 
                                                "id": "anime-id" 
                                            }
                                        ] 
                                    }
