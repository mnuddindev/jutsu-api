High-performance REST API

Modern anime data service built in Go

Unified endpoints for spotlights, rich anime metadata, streaming sources, schedules, characters, studios, search, and observability — all backed by Go Fiber, Redis caching, and structured logging.

Explore API Reference View source

Base URL

http://localhost:8080/api

Formats

JSON · UTF-8

Rate limiting

Not enforced (self-manage)

Quick start

Call any endpoint via HTTPS — no auth required.

Install deps

make install

Run server

make run

Generate docs

make swagger 
curl "http://localhost:8080/api/"

Error model

Every failure response returns a consistent envelope.

{
  "success": false,
  "message": "Why the request failed"
}

Endpoint spotlight

Grouped by capability with inputs and expected payloads.

Home overview

GET /api

  • Spotlights, trending, top-ten, schedule snapshot
  • Cached optionally via Redis per route TTL
  • Use to populate landing experiences

Top ten

GET /api/top-ten

  • Separate buckets for today, week, month
  • Each item follows TopTenItem schema

Anime info

GET /api/info?id=slug

  • Returns synopsis, stats, seasons, recommendations
  • Integrates Qtip sidebar data

Random anime

GET /api/random

  • Full AnimeDetail payload
  • Use GET /api/random/id for lightweight IDs

Qtip

GET /api/qtip/:id

  • Sidebar metadata block mirrored from upstream
  • Helpful for tooltips & highlight cards

Episodes

GET /api/episodes/:id

  • Episode list + filler flags per show
  • Pair with servers + stream

Servers

GET /api/servers?ep=107257

  • Enumerates server + quality pairs
  • Use with type=sub|dub

Stream & fallback

GET /api/stream/:id

  • Returns primary & fallback media sources
  • Tracks metadata and intros/outros

Search

GET /api/search?keyword=naruto

  • Supports advanced filters (type, status, season)
  • Paginated SearchResult payload

Filter

GET /api/filter

  • All filters optional, matches site UI
  • Date range support via sy/sm/sd + ey/em/ed

Suggestions

GET /api/search/suggest

  • Keyword completion for instant search

Top search

GET /api/top-search

  • Hot keywords from upstream analytics

Schedule

GET /api/schedule?date=2025-01-18&tzOffset=-330

  • Daily grid respecting timezone offsets
  • Useful for broadcast calendars

Next episode

GET /api/schedule/:id

  • Returns next airing episode metadata

Character list

GET /api/character/list/:id

  • Paginated character + voice actor pairs

Character detail

GET /api/character/:id

  • Biography, voice actors, animeography

Voice actor detail

GET /api/actors/:id

  • Roles, profile, and featured work

Producer & studio

GET /api/producer/:id · GET /api/studio/:id

  • Paginated catalogue of associated anime

Watchlist

GET /api/watchlist/:userId(/:page)

  • User-specific catalog mirrors original service

Platform health

GET /health · /ready · /live

  • Inline cache + upstream diagnostics

Schema primer

Key payloads surfaced most frequently.

Spotlight

Used on /api home response.

  • id, data_id, localized titles
  • Nested tvInfo for durations, release windows

AnimeCard

Reusable compact tile.

  • Poster, rating, duration, episode counts
  • Used in categories, search, watchlist

AnimeDetail

Full metadata set.

  • results.data with synopsis + stats
  • Includes seasons, relatedAnime, recommended

StreamInfo

Streaming payload.

  • Primary + fallback streamingLink arrays
  • Tracks, intro/outro cues, server metadata

ScheduleItem

Daily/next episode entries.

  • Title, releaseDate, localized time, episode number

SearchResult

Search & filter envelope.

  • Pagination fields page, totalPage, hasNext
  • Data array of AnimeCard
